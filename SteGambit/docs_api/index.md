# SteGambit API Documentation

Welcome to the technical documentation for **SteGambit**, a cross-platform tool for secure "File-in-File" steganography.

## Documentation structure

- **Services** — Facade layer; pipeline orchestration.
- **Core** — Cryptography and steganography algorithms, and format adapters.
- **Models** — DTOs passed between layers.
- **GUI** — PyQt6 widgets, dialogs, and the main window.

## Architecture overview

See [Architecture](architecture.md) for the C4 diagrams and a description of the layered architecture.
