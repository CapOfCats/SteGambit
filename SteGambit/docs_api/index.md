# SteGambit API Documentation

Добро пожаловать в техническую документацию **SteGambit** — кроссплатформенного инструмента для безопасной стеганографии "File-in-File".

## Структура документации

- **Services** — Фасадный слой, оркестрация пайплайна.
- **Core** — Алгоритмы криптографии, стеганографии, форматные адаптеры.
- **Models** — DTO для передачи данных между слоями.
- **GUI** — Виджеты PyQt6, диалоги, главное окно.
